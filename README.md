# ⚡ AngularJS Code

A collection of basic AngularJS programs demonstrating the core concepts of AngularJS. This project is designed for beginners to understand data binding, directives, services, events, and simple web application development.

## ✨ Topics Covered

- Data Binding
- One-Way Data Binding
- Event Handling
- Login Form
- ng-repeat
- ng-switch
- ng-if
- $http Service
- Custom Service
- Resource Service

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript
- AngularJS 1.x

## ▶️ How to Run

1. Clone the repository.
2. Open the project in Visual Studio Code or any code editor.
3. Open any HTML file in your web browser.
4. Explore the AngularJS examples.

## 🎯 Learning Objectives

- Learn AngularJS fundamentals.
- Understand data binding concepts.
- Work with AngularJS directives.
- Handle events using AngularJS.
- Use built-in and custom services.
- Build simple AngularJS web applications.
